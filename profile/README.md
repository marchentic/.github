<h1 align="center">marchentic</h1>

<p align="center">
  Portable agent plugins for Claude Code, Cursor, GitHub Copilot, and OpenAI Codex.
</p>

---

**marchentic** ships marketplace plugins — rules, skills, agents, and slash
commands that change how the agent works, not just which files it opens.

### Start here

| | |
| --- | --- |
| Marketplace | [marchentic/marchentic](https://github.com/marchentic/marchentic) |
| Plugin ids | `marchentic-<short>` |
| Marketplace name | `marchentic-marketplace` |

```text
# Claude Code / Codex
/plugin marketplace add marchentic/marchentic
/plugin install marchentic-global@marchentic-marketplace
```

Cursor: **Dashboard → Settings → Plugins** → import
`https://github.com/marchentic/marchentic`.
